# AKNexus

**AKNexus — 轻量级、模块化、可组合的 .NET 8 应用开发框架**

AKNexus 是面向企业级业务系统设计的 .NET 应用基础框架，强调 **组件自治、自动装配、宿主解耦与最小侵入**，为 MES、工业物联网及通用后台系统提供可复用的基础设施。

### 核心特性

- **组件自治与自动装配**：通过 `IAssemblyRegistrar` 实现程序集级组件自描述和自主注册，减少宿主与业务模块的直接耦合。
- **双阶段生命周期**：通过 `Configure(IKernelBuilder)` 与 `Use(IKernelApplication)` 分离服务注册和应用管线初始化，支持按 `Order` 有序执行。
- **统一 Kernel 抽象**：封装应用构建、依赖注册及运行生命周期，实现框架能力与业务代码分离。
- **可替换的数据访问基础设施**：抽象数据库连接配置和上下文切换，面向多种关系型数据库的适配需求。
- **异步日志体系**：基于 `Channel` 与 `BackgroundService` 解耦日志生产和处理过程。
- **开箱即用的 Web 基础能力**：集成 JWT、API 版本控制、异常处理、CORS、健康检查及标准化中间件管线。
- **渐进式扩展**：允许按业务需要接入模块，避免不必要的后台管理功能和重型基础设施依赖。

### 设计理念

**让框架负责基础设施，让组件负责自身能力，让业务代码专注业务逻辑。**

不追求功能堆砌，而是通过清晰的扩展边界、可控的生命周期以及低侵入的装配机制，降低业务系统的初始化、迁移和长期维护成本。
